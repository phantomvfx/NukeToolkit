# NukeDevSandbox

Workspace for building Nuke tools, gizmos, and NukeX extensions.

- **`gizmos/`** — Nuke `.gizmo` files
- **`python/`** — Python tools and scripts
- **`reference/`** — versioned Nuke documentation imports (see
  [`reference/nuke16/`](reference/nuke16/README.md) — Nuke 16 docs, index at
  `reference/nuke16/DOCS_INDEX.md`)

See [`CLAUDE.md`](CLAUDE.md) for the full layout and reference-library registry.
