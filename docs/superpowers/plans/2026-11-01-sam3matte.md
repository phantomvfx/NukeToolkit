# SAM3Matte Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A NukeComfy tool, `SAM3Matte`, whose Generate button sends a plate to ComfyUI, runs SAM3 over a frame range, and brings back one mask sequence per object as alpha, per-object channels, a Cryptomatte layer and an editable Roto.

**Architecture:** One `.nk` Group built by `build/build_sam3matte.py`. All logic that does not need Nuke lives in leaf modules (`sam3matte_graph`, `_crypto`, `_chunks`, `_hints`, `_png`, `_roto_core`, `_versions`) tested from plain Python. A Nuke-free `sam3matte_runner` drives ComfyUI chunk by chunk from a worker thread (testable against a fake HTTP server). `sam3matte.py` is the thin Nuke layer (render, sampling, button callbacks, versions); `sam3matte_roto.py` is Make Roto.

**Tech Stack:** Python 3.11 (Nuke 16.1), stdlib + `nuke` + `nukescripts` inside Nuke, pytest 9.1.1 (on PATH as `python`) for pure tests, `Nuke16.1.exe -t` for Nuke tests, ComfyUI 0.43.2 at 127.0.0.1:8188 for live tests.

**Spec:** `L:\Nuke\docs\superpowers\specs\2026-11-01-sam3matte-design.md`. Repo rules: `L:\Nuke\CLAUDE.md`, `L:\Nuke\tools\comfy\CLAUDE.md`. Pattern: Flux3Klein (`tools/comfy/python/flux3klein.py`, `flux3klein_graph.py`, `build/build_flux3klein.py`).

## Review Focus

Failure modes the spec implies but a happy-path test would miss, most likely first. Each has a named test in the owning task.

1. **Nothing found.** The prompt or Select yields zero objects (Detect returns an empty batch). Expect a clear status ("Nothing found for ..."), no empty version, no traceback. (T9 `test_nothing_found_creates_no_version`, T11 `test_nothing_found_status`.)
2. **Odd ranges.** First frame 0 or not 1001, a one-frame range, key frame at either end, key outside the range, plate narrower than 1024. Expect correct file numbering and a plain error for a bad key frame. (T3 `test_plan_key_at_last`, `test_plan_single_frame`, `test_plan_bad_args`, `test_tracking_size_small_plate`; T9 `test_first_frame_zero`; T11 `test_key_outside_range_error`.)
3. **Empty Select / empty Stencil on the key frame.** Empty Select must not send a request; empty Stencil is simply no exclude points. (T4 `test_hint_points_empty_when_nothing_inside`; T11 `test_empty_select_error`.)
4. **Server trouble mid-run.** ComfyUI unreachable, `execution_error` (out of memory) in chunk 3, or Cancel during chunk 2. Expect finished chunks kept as a partial version, a readable status, no hung thread, and Resume working. (T9 `test_execution_error_keeps_partial`, `test_cancel_between_chunks`, `test_resume_skips_completed_chunks`.)
5. **Garbage in knobs and missing files.** Objects text such as `7`, `person_9`, `,,`; a version whose folder was moved or cleaned. Expect "no objects" (alpha black) and a status line, not an exception. (T7 `test_parse_objects_garbage`; T11 `test_missing_folder_status`.)

## Contracts (every task relies on these; do not deviate)

**C1. Files, names, paths.**
- `job` id = `f"{node.name()}_{YYYYmmdd_HHMMSS}"`. Temp root = `NUKECOMFY_TEMP` env, else `bridge._resolve_temp_folder()` (same 4 lines as `flux3klein._temp_folder`, with `/` separators). Version folder `V = <temp>/<job>`; masks are `V/obj<k>.<frame:04d>.png` (Nuke pattern `obj<k>.####.png`), k = slot 0..7, frame = the plate's frame number. Plate scratch is `V/_plate/f_<frame-first:05d>.png` (tracking size) and `V/_plate/key.png` (full size); `_plate` is deleted when the job ends.
- Uploads (via `api_client.upload_image(path, subfolder)`, which returns the LoadImage value): key `nukecomfy/<job>_key.png` (subfolder `nukecomfy`, file `<job>_key.png`); seed `<job>_seed<chunk>_<j>.png` in `nukecomfy`; chunk frames in subfolder `nukecomfy/<job>_c<chunk>` (if `UPLOAD_NESTED` is False: `nukecomfy_<job>_c<chunk>`), files `f_<frame-first:05d>.png`, uploaded in ascending frame order. A backward chunk is uploaded ascending and reversed in the graph.
- SaveImage prefix is unique per prompt: `NukeComfy/<job>/detect/obj`, `NukeComfy/<job>/c<chunk>/obj`. Frame of an output image = its position in `history[pid]["outputs"][node_id]["images"]`, never parsed from the file name. ComfyUI has no route to delete input files; uploaded frames stay in `input/nukecomfy*`. The final status/log line says how many files were left.

**C2. Graph builder (`sam3matte_graph.py`, T1).** Pure, leaf.
```python
CKPT = "sam3.1_multiplex_fp16.safetensors"; MAX_SLOTS = 8
# --- settings block: T8 may edit these three constants after measuring ---
UPLOAD_NESTED = True               # VHS_LoadImages directory "nukecomfy/<job>_c1" accepted by the server
WHOLE_RANGE_SEED_WITH_TEXT = True  # Video Track accepts initial_mask + conditioning together
SPLIT_DETECT = False               # Detect with text AND points in one node works
def build_detect(p: dict) -> tuple[dict, dict]
def build_track(p: dict) -> tuple[dict, dict]
```
Both return `(workflow, outputs)`; `workflow` is an API-format prompt (string node ids), `outputs` maps each SaveImage node id to `{"obj": int | None, "pass": str}`.
- `build_detect` keys: `key_image` (LoadImage value), `text` ("" = none), `positive`, `negative` (lists of `{"x": int, "y": int}`, pixels, top-left origin), `threshold` (0.5), `prefix`. One `SAM3_Detect` with `individual_masks=True`, `refine_iterations=2`; coordinates via `PrimitiveStringMultiline` holding `json.dumps(list)`; negatives are dropped when there are no positives (negative-only returns a stray mask); no bounding-box input (see Decisions). One `MaskToImage` -> one `SaveImage` with id `"detect_save"`; `outputs == {"detect_save": {"obj": None, "pass": "key"}}`; image i of that node is object i (points object first, then text objects in subject order).
- `build_track` keys: `directory` (VHS directory value), `reverse` (bool), `track_w`, `track_h`, `seeds` (list of LoadImage values, one per tracked object, may be `[]`), `text`, `max_objects`, `n_save` (slots to save, 1..8), `prefix`, `pass_name` (`"fwd"|"bwd"|"text"`). `VHS_LoadImages` (`directory`, `image_load_cap=0`) -> optional `ReverseImageBatch` (only when `reverse`) -> `SAM3_VideoTrack(detection_threshold=0.5, detect_interval=1, max_objects=min(64, max(max_objects, len(seeds), 1)))`. Seeds: each `LoadImage` -> `ImageBatch` chain -> `ImageScale(upscale_method="bilinear", width=track_w, height=track_h, crop="disabled")` -> `ImageToMask(channel="red")` -> `ThresholdMask(value=0.5)` -> `initial_mask`. `text` non-empty: `CLIPTextEncode` -> `conditioning`. Neither seeds nor text: `ValueError`. Per slot j < n_save: `SAM3_TrackToMask(object_indices=str(j))` -> `MaskToImage` -> `SaveImage` with id `f"save{j}"`; `outputs == {f"save{j}": {"obj": j, "pass": pass_name}}`.

## Decisions the spec left open (all reported to the user)

1. **Detect is its own prompt (prompt 0).** Nuke learns N objects, can drop Stencil-covered text objects and enforce the global Max objects before tracking, and every key-frame chunk has the same shape (seeded track, forward or reversed). This replaces "Detect and two Video Tracks in one graph" from the spec; the chunking section already implies seeded passes.
2. **Select's bounding box is not sent.** `SAM3_Detect.bboxes` is a force-input `BOUNDING_BOX` with no primitive producer in core, and a box without text runs a separate decoder path that adds a duplicate Select object. Select is points only (spike run 2: IoU 0.993).
3. **Stencil's area drop applies to text objects even with Select connected** (negative points only shape the points object; text detections ignore them). The Select object itself is never dropped.
4. **Names.** `select` for the points object; `<subject>_<n>` only when the prompt has exactly one subject; otherwise `obj<k>` (Detect output does not say which subject an object came from; T8 re-checks).
5. **Regions are 4-connected**; regions under 16 px at trace resolution count as empty.
6. **Slots saved = Max objects** (default 4), not always 8, so black slots are not downloaded.
7. **Plate render goes through the script's default display/view, as the spec says** (orchestrator correction): inside the Group, an `OCIODisplay` node (`display` = the root's default display, `view` = its default view, read from the script's OCIO config at render time) before a **raw** 8-bit PNG Write. Not the Write's default 8-bit colourspace: on an ACES plate that is an sRGB encode with no tone mapping, so highlights clip and SAM3 sees a different image from the artist. The spike used `sRGB - Display` on the cg-config v2.2 and looked right. With colour management off (Nuke default LUTs), fall back to a non-raw sRGB Write.
8. **Resume** is a Generate with the same parameters while the current version is `partial`; it appends to that version's folder and replaces that version in place.
9. Input grid for Select/Stencil sampling is 48 columns wide; rows follow the aspect.
